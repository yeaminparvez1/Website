02 · Website colours / ওয়েবসাইটের রং

03 · Add your own sections / নতুন Section যোগ

যেমন: Publications, Training, Volunteer Experience, Awards, Gallery ইত্যাদি।

04 · Save changes / পরিবর্তন সংরক্ষণ

গুরুত্বপূর্ণ: প্রথমে নিচের বাটনে চাপ দিলে settings.json নামে একটি ফাইল ডাউনলোড হবে। এরপর GitHub repository-তে গিয়ে পুরোনো settings.json ফাইলটি Replace/Upload করতে হবে। Upload হলেই ওয়েবসাইটে পরিবর্তন প্রকাশ পাবে। শুধু এই পেজে পরিবর্তন করলে Live website বদলাবে না।

How to publish / GitHub-এ কীভাবে আপলোড করবে?

১. Download my changes বাটনে চাপ দিয়ে settings.json ডাউনলোড করো।

২. GitHub Portfolio repository খোলো।

৩. settings.json ফাইলটি খোলো → পেন্সিল/Edit আইকনের পাশের Upload files অপশন বা repository-র Add file → Upload files ব্যবহার করে নতুন ফাইলটি আপলোড করো। Replace confirmation এলে Confirm করো এবং Commit changes দাও।

৪. GitHub Actions-এ deployment শেষ হলে ওয়েবসাইট Refresh করো।

নতুন Section-এর শিরোনাম ও লেখা যোগ করা যাবে। একদম নতুন ধরনের design/layout, project card বা navigation পরিবর্তন চাইলে আমাকে বললেই আমি করে দেব।
